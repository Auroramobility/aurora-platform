# Aurora Mobility — Product Roadmap

Version: 1.0

Status: Living Document

---

# Purpose

This roadmap defines how Aurora Mobility evolves from an MVP into a production-ready electric vehicle ownership platform.

Every milestone must support Aurora's mission:

> Make electric vehicle ownership accessible, affordable, and transparent for everyday people.

---

# Development Philosophy

We build vertically.

Instead of building dozens of disconnected features, every phase should complete an end-to-end user experience before moving to the next.

Every completed milestone should leave Aurora in a usable state.

# Development Rules

Before starting any feature, ask:

1. Does this help someone own an EV?
2. Does this increase trust?
3. Does this simplify the ownership journey?
4. Is this scalable?
5. Does this align with Aurora's mission?

If the answer is "No", revisit the design before writing code.
